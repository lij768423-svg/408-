使用说明

从刷题到复习
目录 Guide

推荐流程：选章节做题 → 看仪表盘 → 完成今日复习 → 遇到卡点再问 AI。

新用户入口

这套系统能做什么

做题后，系统会自动更新正确率、错题和复习计划；学习仪表盘把这些记录转成今天该复习什么。AI 和个人知识库用于处理难点，不影响基础刷题。

选择题目范围 作答并看解析 按计划复习 沉淀难点
刷题
按科目、章节和模式生成题单，提交后记录作答结果。
学习仪表盘
查看完成度、正确率、错题、到期题目和优先复习章节。
个人知识库
保存并管理概念笔记或题目复盘；需要登录和完整后端。

第一次使用

  1. 进入“刷题”，在左侧选择科目和章节。
  2. 第一次学习建议选“顺序”；复盘时可选“随机”“错题”“收藏”或“未做”。
  3. 选择答案后点击“提交”。多选题可连续选择多个选项。
  4. 查看正确答案、你的答案和题库解析，再进入下一题。
  5. 完成一组后打开“学习仪表盘”，按优先章节或“开始今日复习”继续。

建议第一轮：选一章 → 顺序做 10 题 → 查看仪表盘 → 完成已到期复习。

刷题与搜索

左侧选择科目、章节和模式后会生成新的题单。切换范围时会回到该题单第一题。

顺序 / 随机
顺序适合初学；随机用于检查是否真正掌握。
今日复习
只做当前范围内已经到期的复习题，默认最多 20 题。
错题 / 收藏
错题显示当前仍未做对的题；收藏用于保留典型题和易混题。
未做 / 全部
未做用于补进度；全部会跨科目随机生成题单。
即时判分
单选选择后立即判断；多选选错时立即判错，选齐正确选项时判对。
全文搜索
点击顶部“搜索题库”或按 Ctrl/Cmd + K，可搜索题干、选项和解析，并按来源和年份筛选。

搜索结果点击后会直接跳到对应题目；按 Esc 可关闭搜索窗口。

仪表盘与间隔复习

今日待复习
已经到期、建议今天完成的题目数量。
优先章节
综合完成度、正确率、错题和到期题目推荐最多 3 个章节，点击即可开始。
章节明细
按科目查看完成度、正确率、错题、待复习数和最近 7 天变化。
近期学习
展示最近 14 天答题量和正确情况，用于判断学习节奏。
  • 答错后，题目当天进入复习计划。
  • 做对后，间隔依次延长为 1、3、7、14、30、60 天。
  • 连续做对 2 次后移出普通错题列表，但仍保留长期复习计划。
  • 之后再次答错，会清空连续正确并立即重新到期。

“今天已清空”表示当前没有到期题目，不是数据丢失。仪表盘标题旁的“?”可随时查看收录规则。

AI 讲题与保存

右侧 AI 会带上当前题目、选项、用户选择、正确答案和题库解析。输入具体问题后按 Enter 或点击“询问 AI”；生成中再次点击可以停止。

预设问题
可直接选择“讲解思路”“逐项排除”“错因分析”或“生成错题卡”。
自由追问
例如“为什么不选 B”“题干的限定词在哪里”“什么是管程”。
复制上下文
复制当前题目的 Markdown 上下文。服务器 AI 不可用时，可粘贴到外部 AI。
保存概念
保存最近一次具体概念问题和 AI 回答，不发送题干、选项、答案或作答字段。
保存题目
保存当前题干、选项、正确答案、题库解析、作答状态和 AI 讲解。

“保存概念”和“保存题目”都需要登录。AI 可能出错，最终结论以题库解析、教材和考纲口径为准。

个人知识库

知识库按账号隔离，保存内容为 Markdown。默认显示概念问题，也可切换到全部问题或题目问题。

浏览与分类
左侧按科目显示目录；顶部可切换“全部问题 / 概念问题 / 题目问题”。
搜索
输入关键词后按 Enter 或点击“搜索”，匹配标题、路径、标签和正文。
预览与编辑
点击笔记查看 Markdown 全文；点击“编辑”可直接修改并保存。
继续追问
可基于当前笔记提问，或使用口诀、易错点、自测题和表格等预设。
写回笔记
AI 回答不会自动修改文件；确认后再保存追加到当前笔记。
删除
文件会移动到个人知识库的 .trash，不是立即永久删除。

账号与学习数据

LOCAL 模式

  • 无需账号，可使用刷题、搜索、仪表盘和间隔复习。
  • 数据只保存在当前浏览器，不能跨设备同步。
  • 不能使用服务器 AI 和个人知识库。

登录模式

  • 自动同步作答、错题、收藏、复习计划、活动和部分偏好。
  • 状态显示 SYNCING、SAVED 或 SYNC FAIL。
  • 支持页面内 AI、个人知识库和修改密码。
导出记录
下载 JSON 备份，适合迁移浏览器或长期存档。
导入记录
选择之前导出的 JSON 恢复学习数据；登录状态下会继续同步。
题库预览
查看全题库状态，不会修改记录；点击题号才会跳到对应题目。
更改密码
输入当前密码和两次新密码；成功后当前设备保留登录，其他会话退出。
退出登录
停止服务器同步；当前浏览器中的本地缓存仍会保留。

常见问题

页面显示 LOCAL
当前未连接完整后端或尚未登录。基础刷题正常，数据保存在浏览器。
AI 没反应
确认已登录且 AI 状态可用；失败时使用“复制上下文”粘贴到外部 AI。
保存概念失败
先提出一个具体概念问题并得到回答，再点击“保存概念”。寒暄或空问题不会保存。
知识库为空
新账号默认没有笔记。先在 AI 面板明确保存概念或题目，再进入知识库。
搜索提示 server error
知识库上游暂时不可用或超时，刷新后重试；基础刷题不受影响。
同步失败
本地记录仍会保留。检查网络后继续操作，恢复连接时会再次同步。
换浏览器没有进度
LOCAL 数据不会自动迁移，请在旧浏览器导出记录，再在新浏览器导入。

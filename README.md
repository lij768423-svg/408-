# 408 考研刷题库

轻量级网页刷题应用,基于王道 2026/2027 四本 408 教材的精选题库。

## 快速开始

```bash
# 方式 1:直接双击 index.html 在浏览器中打开
open ~/408-quiz/index.html

# 方式 2:起本地服务器(端口 8767)
cd ~/408-quiz && python3 -m http.server 8767
# 然后访问 http://127.0.0.1:8767/
```

> 💾 所有记录(错题/收藏/答题统计/已答记录)都存在浏览器的 `localStorage` 里,
> 浏览器关闭、重启电脑都不会丢。换浏览器或清空浏览数据会清空。
>
> ⚠️ `file://` 和 `http://127.0.0.1:8767` 在浏览器看来是两个不同的来源(origin),
> `localStorage` 互相隔离 — **请固定使用同一种方式打开**,否则记录会分裂。

## 功能

- **4 本书 + 全部模式**:操作系统 / 数据结构 / 计算机组成原理 / 计算机网络 / 📚 全部 1777 题(跨书随机)
- **章节切换**:每本书可单独选章节,或"全部章节"
- **5 种模式**:
  - 顺序 — 按教材顺序刷
  - 随机 — 打乱顺序
  - 错题 — 只刷做错的
  - 收藏 — 只刷收藏的
  - 全部随机 — 跨书随机出 N 题(可调 20/50/100/200)
- **即时判分开关 ⚡**:
  - 单选题:点 A/B/C/D 立即判分(对/错 + 解析)
  - 多选题:选对继续,选错立即判错,选全立即判对
  - 关闭时:经典「选 → 提交 → 判」流程
- **4 个选项 + 提交判对错**:立即显示对错 + 正确答案 + 详细解析
- **上一题 / 下一题 / 跳过 / 显示答案**
- **错题自动入错题本**,答对的题自动从错题本移除
- **收藏好题**(按 `F` 键快速收藏)
- **做完一组自动提示「下一组」** — 全部模式下完成 N 题自动出现按钮
- **localStorage 持久化**:错题、收藏、答题统计、最后选的书、即时判分开关、每刷题数都自动保存

## 键盘快捷键

| 键 | 作用 |
|---|---|
| `A` / `B` / `C` / `D` | 选择对应选项(多选题支持累积选择) |
| `Enter` | 提交 / 下一题(根据当前状态) |
| `←` / `→` | 上一题 / 下一题 |
| `Space` | 显示答案 |
| `F` | 收藏 / 取消收藏 |

## 题库规模

- 4 本书 / 26 章 / **1777 题**(单选题 1740 + 多选题 37)
- 数据文件:`data.json` (~2.1 MB)
- 解析覆盖率:100%(每题都有题面 + 4 选项 + 答案 + 解析)

## 重新生成数据

题库数据由 vault 内的提取脚本生成:

```bash
cd ~/Documents/文稿\ -\ dajiji的MacBook\ Air/Obsidian\ Vault
python3 wiki/tools/_extract_questions.py
```

脚本会读 `wiki/sources/{操作系统,数据结构,计算机组成原理,计算机网络}/chapters/ch*.md`,
按章节配对「本节习题精选/答案与解析」,提取 4 选项题(单选/多选),
输出到 `~/408-quiz/data.json`。

## 设计原则

- **不污染 vault**:应用和数据都在 vault 外,刷新题库只重跑脚本
- **零依赖**:不需要 Node / npm / 构建步骤
- **离线可用**:数据全在本地 JSON,无网络请求
- **快速**:3000 题级单文件加载 < 1s,DOM 简单无性能问题

## 已知限制(MVP 范围外)

- ❌ 综合应用题(解答题)未提取(没有 A/B/C/D 选项)
- ❌ 真题年份标签未做专门分类
- ❌ 答题计时
- ❌ 移动端优化
- ❌ 全文搜索
- ❌ 答题统计图

这些功能可在后续迭代添加。

## 浏览器兼容性

需要支持 ES6+ 和 `fetch` API 的现代浏览器(Chrome 90+ / Safari 14+ / Firefox 88+ / Edge 90+)。
